02전자결재 용어 정리

전자결재를 시작하기 전 자주 쓰는 용어입니다.

기안(상신) · 품의
업무 담당자(책임자)가 보고를 통해 업무 의사결정을 완료하는 것. '재가(裁可)'로 순화하여 쓰기도 함. 품의는 공손하게 허락받는 상황, 기안은 안건·의견을 제시한다는 뜻.
수신처
결재 문서를 받아 검토·승인해야 하는 부서. 주된 결재 대상 혹은 담당부서로 내용에 대한 책임과 의사결정 권한을 가짐. (예: 재무 관련 - 재무 팀장, 물류 관련 - 오퍼레이션팀장)
참조자
결재 문서를 열람만 할 수 있으며 의사결정에는 관여하지 않음. 단순히 내용을 공유받아 참고하는 역할 (유관부서 담당자).
시행자
결재가 완료된 후 실제 작업을 담당하는 사람. 문서에 명시된 업무 수행 책임을 가짐. (예: 지출 결의서 - 자금담당자, 제품 출고 신청서 - 출고 담당자)
전결
해당 업무의 전결권자로 보임된 자가 결재문서에 대해 결정을 완료하는 것. 전결권자는 해당 업무의 모든 책임과 권한을 가짐.
합의
업무 추진 시 관련되는 타 부서 담당자에 대한 동의 과정.
거부(반려)
결재권자가 문서 내용이 충분하지 않거나 동의하지 않아 기안자에게 돌려보내는 것.
미결 / 보류
미결: 아직 결재를 하지 않은 경우. 보류: 결재자가 의사결정을 잠시 미루는 것.
후결(비활성화)
결재 후 처리가 끝난 서류를 확인하는 것.
참조(수신참조)
결재가 진행되는 과정을 알고 있어야 하는 자이며, 결재과정에서 의견을 제시할 수 있음.
공람 / 회람
결재가 모두 완료된 이후에 문서를 열람할 수 있으며 결재과정에는 참여할 수 없음. 공람(供覽)은 '여러 사람이 보게 한다'는 뜻으로 '돌려 본다'는 의미.

03결재 문서 작성

전자결재 화면에서 결재작성 클릭 → 아래 순서로 문서를 완성합니다.

① 양식 선택

공통양식재무 / 회계인사 / 총무
기안서지출품의서(연동X)구매요청서
교육신청서지출결의서(연동X)도서구입신청서
업무협조전업무경비청구서경조비지급신청서

보고서지출결의서(연동) — 연동 진행 중시말서
교육결과보고서지출결의서(예산) — 연동 진행 중사직서
법인서류사용신청서

② 문서 제목 작성

  • 작성 규칙: [문서 종류] + 핵심내용 + 세부 정보(선택)
  • 예시: [보고] 2025년 01월 월간 실적 보고의 건 / [인사] 2025년 조직 개편 인사 발령의 건 / [요청] 신규 장비 구매 승인의 건
  • "긴급", "검토 요청드립니다" 같은 표현은 제목에 넣지 말고 본문에서 다루기
  • 제목은 짧고 간결하게 핵심을 전달할 수 있도록 작성

③ 결재선 지정

  • 기본 구조: 상위 결재자(결재) → 유관 부서 책임자(합의) → CEO(병렬 결재)
  • 병렬 결재 지정 방법: 대표이사 1명 선택 후 '결재' 클릭 → 추가 1명 선택 후 '병렬' 클릭

④ 참조문서 / 첨부파일 / 기타 항목

  • 지출 결의서 상신 시, 지출 품의서 참조 문서 추가 필수 (총 예산 1,000만원 이상 건)
  • 참조문서·첨부파일은 마우스로 파일을 끌어와 등록 가능
  • 문서유형(일반문서 등) / 보안등급 / 긴급도 / 보존연한(영구보존 등) / 문서함 항목을 함께 설정

04결재 경로

문서 유형에 따라 결재 경로(결재/합의/전결/참조/시행자)가 다르게 설정됩니다. 아래는 대표적인 문서 유형별 흐름 요약입니다.

구분문서 종류결재 경로 특징
공통양식기안서작성 부서장이 정해지지 않은 경우 소속 상사 지정 가능
업무협조전수신·참조 부서를 지정해 협조 요청
보고서상위 결재자에게 보고 목적으로 상신
재무 / 회계지출품의서 / 지출결의서1,000만원 이상 여부에 따라 결재 단계·병렬 결재 구성이 달라짐 (FA 전결 조건 포함)
업무경비청구서사용 부서장 결재 → FA 승인
휴가 / 근태연차, 반차 등본인 → 팀장 승인(팀장은 담당대표), 일괄(반려) 처리 가능
경조사 관련HR&GA 확인 필요 항목 별도 표시
인사 / 총무(계)구매요청서사용 부서장 결재 → FA/총무 승인
도서구입신청서사용 부서장 결재 → HR&GA 확인
법인서류사용신청서 / 사직서부서장 결재 → HR&GA 참조·처리
업무인계인수서 / 시말서부서장 결재(병렬) → HR&GA 참조

※ 실제 결재 경로 매트릭스(작성자/검토기관/승인부서/합의 등 상세 컬럼)는 시스템 내 문서 작성 화면에서 문서 종류 선택 시 자동으로 적용됩니다. 원본 노션 페이지에는 문서별 상세 매트릭스 표가 이미지로 첨부되어 있으니 세부 조건이 궁금하면 원본을 함께 확인해 주세요.

05결재 처리

  • 결재 대기 문서(미결 문서) 확인: 결재자는 '결재 HOME' 화면 또는 '결재수신함-미결문서' 메뉴에서 확인. 상신자는 '상신/보관함-상신문서' 메뉴에서 진행 현황 확인 가능
  • 문서 내용 검토: 결재자는 기안의 본문을 면밀히 검토 후 화면 상단 메뉴로 의사결정
  • 승인 / 거부(반려) / 보류 선택
  • 의견 작성(필요 시): 의사결정에 따른 코멘트를 남길 수 있음

06결재 소요시간 및 기한

  • 결재와 합의는 1인당 영업일 기준 12시간 이내에 의사결정을 완료해야 합니다.
  • 결재/합의자에게 주어진 시간이 경과하기 전까지는 의사결정을 재촉할 수 없습니다.
  • 보류의 경우 재검토 시간으로 12시간이 추가 부여됩니다.
  • 결재 소요시간은 최대 (결재/합의 인원 × 12시간) 입니다.
  • 최대 시간 외 수정 및 보완 시간을 고려하여, 시간적 여유를 두고 사전에 업무를 진행해야 합니다.
!업무를 미뤄두었다가 한 번에 상신하는 경우, 결재 상황에 따라 업무가 늦어질 수 있습니다.

07기안자와 결재자의 의무와 책임

기안자

  • 결재문서 작성 시 해당 내용을 구체적으로 작성해야 합니다.
  • 실제 담당자가 결재문서를 작성하여야 하며, 이에 대한 책임을 집니다.
  • 의사결정이 필요한 모든 업무는 최종 결재가 완료된 이후에 진행해야 합니다.
  • 결재문서 관련 수정 및 보완 의견이 있는 경우 반드시 수정 후 재상신해야 합니다.
  • 특이사항이 발생한 경우 반드시 사유와 목적을 작성해야 합니다.

결재자

  • 기안자가 상신한 결재문서를 면밀히 검토하여 의사결정을 해야 합니다.
  • 결재자는 영업일 기준 12시간 내에 내용을 검토하여 의사결정을 해야 합니다.
  • 결재문서에 수정 및 보완이 필요한 경우, 의견을 남겨 기안자가 확인할 수 있도록 합니다.
  • 내용에 문제가 있을 경우 해당 내용을 보류 또는 반려할 수 있습니다.
!본인의 업무는 반드시 본인이 직접 상신합니다. 타인의 업무를 대리로 상신하지 않으며, 결재가 완료되기 전 결재를 예상하고 사전에 업무를 진행하는 경우 사안에 따라 징계를 받을 수 있습니다.

08전자결재 사용 팁 🚀

  • 💡 신속한 피드백: 결재 요청을 받으면 가능한 빨리 처리해주세요. 빠른 의사결정이 회사의 성장 속도를 높입니다.
  • 🎯 명확한 설명: 결재 문서 작성 시 핵심을 간단명료하게 작성해주세요. 불필요한 형식적인 내용은 최소화합니다.
  • 🤝 열린 소통: 결재 과정에서 궁금한 점이 있다면 메신저나 대면으로 자유롭게 논의해주세요.
  • 📱 모바일 활용: 이동 중이나 외근 시에도 모바일로 신속하게 결재해주세요.
  • 🎨 창의적 제안: 기존 양식에 얽매이지 말고, 필요한 경우 새로운 형태의 결재 양식을 제안해주세요.
✓충분한 협의와 내용 공유: 업무 진행 시 사전에 결정권자와 유관 부서에 관련 내용을 구두 또는 메일로 공유하고 충분한 협의가 이루어져야 합니다. 여럿의 의견이 필요한 경우는 미팅을 통해 공유해 주세요.
!결재와 보고는 다릅니다. 결재는 보고를 하는 것이 아닌 결정권자들의 최종 의사결정을 받는 과정입니다. 사전에 공유하지 않은 내용을 상신하지 않도록 해주세요!

결재 관련 문의사항이 있으시면 Amaranth10 Q&A 게시판에 내용을 남겨주세요.

  5. 공급가액·부가세는 카드사 기준 자동 반영. 실제 사용목적에 따라 조정하며, 부가세 미적용 계정은 부가세를 0원으로 입력해 공급가액과 합계액을 일치
  6. 건별 용도 설정 (자주 쓰는 용도 참고)
  7. 타사 제품 샘플 구매건은 목적별 용도 구분 (아래 표 참고)
  8. 거래처명으로 품목 확인이 안 되는 건은 건별 내역에서 첨부파일 추가
  9. 1개 결제 내역에 2개 이상 품목군이 섞인 경우, 카드사용내역에서 같은 건을 재선택하여 품목군별 금액을 나누어 입력
  10. 지급요청일은 당월 말일자로 입력
  11. 결재라인: 작성자(팀원) → 팀장 또는 작성자(팀장) → 관리대표자 1인 (팀장은 상위 결재자 없음)
  12. 상신 클릭으로 작성 완료

출 / 퇴근 (근무시간 관리)

  • Amaranth 10 PC 메신저로 출근/퇴근 버튼을 클릭합니다.
  • 모바일 출/퇴근은 불가하며, PC 메신저로만 가능합니다.
  • PC 메신저는 그룹웨어 우측 상단 더보기(점 3개) → 다운로드 센터에서 다운로드할 수 있습니다.

개인근무시간동의 (임직원업무관리 > 근무시간)

  • 본인 근무시간을 확인 후 동의하는 메뉴입니다. 금일 근무시간은 퇴근 후 익일 반영됩니다.
  • 매일 본인 근무시간을 확인 후 동의 버튼 혹은 조정신청을 요청할 수 있습니다.
  • 개인근무시간현황 메뉴에서 본인 근무시간현황을 확인할 수 있습니다. 월이 마감되면 본인 한달 근무상태를 체크해 이상 없는지 확인하고, 이상이 있을 경우 조정해서 상태가 전체 승인이 되도록 관리해야 합니다.
!근태 조정 없이 미승인 상태로 누락되는 경우 규제가 강화될 수 있습니다. (예: 성과 평가의 공통 평가 항목 중 근태가 낮은 항목으로 평가될 수 있음) 매월 마감 전 꼭 확인해 주세요.
